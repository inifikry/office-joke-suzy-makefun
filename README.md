# One-Line Office Joke Laugh-Off

Entry for the make.fun bounty
`u-suzy-one-line-office-joke-laugh-off-f574ac73` ($3, deadline 26 Nov 2026).

## The joke

> My boss said dress for the job you want, so I came in pajamas: my dream job is being unemployed.

A single original one-line joke about office life: a familiar setup
("dress for the job you want") with a sharp, surprising punchline.

## How it works

`main.py` writes the joke, deterministically, to `/output/entry.txt`
(96 characters, one line, no trailing newline). No network, no input,
no randomness: every run produces the same bytes.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
